02 / A LITTLE ABOUT ME

I like knowing
how things work.

Parham Azizi↗

I learn best when I have
something to build.

Most of my projects start with something I want to figure out: how a chatbot finds the right information, how a coding agent uses tools, or how to make a codebase easier to explore. I work through the pieces, from the model and database to the API and interface.

I’m especially interested in AI that runs locally. I like being able to see what a system is doing, keep data on my own hardware, and change the parts I need to. Python is what I reach for most often.

I also spend time learning mathematics, especially geometry, topology, and differential geometry. I’m curious about how those ideas connect to computer science, even when there isn’t a project attached.
